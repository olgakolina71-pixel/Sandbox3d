MiniScript v0.1

MiniScript — небольшой командный язык для первых сценариев. Он работает через список разрешённых команд и не исполняет произвольный JavaScript.

Сообщение

say "Привет, мир!"

Показывает сообщение в строке состояния игры.

Создание блоков

spawn grass 0 0 0
spawn stone 1 0 0
spawn wood 0 1 0

Формат: spawn материал x y z. Материалы: grass, stone, wood, sand, brick и neon. Координаты ограничены диапазоном от −100 до 100.

Другие команды

  • help — список команд.
  • clear — подтверждаемая очистка текущего мира.
  • Пустые строки и строки с # в начале игнорируются.
